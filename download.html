What's in the repository

Item Description
World & country-level CAI Daily and monthly Climate Attention Index series, 2014–2022, for 25 countries.
Country exposure estimates (β) Estimated sensitivity of each country's CAI to the global index, used to sort country pairs and firms.
Construction code Text-preprocessing, tf‑idf scoring and cosine-similarity pipeline used to build the index.

See the repository README for full variable definitions and file structure.
